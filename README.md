# CSM-07 Project – Quantum Adders and Subtractors

## Project Overview

This project implements arithmetic operations using quantum computing
and reversible logic gates.

The main objectives are:

- Design a quantum half adder
- Design a quantum full adder
- Design a quantum subtractor
- Implement the circuits using Qiskit
- Study reversible quantum gates
- Decompose quantum circuits into basic gates
- Explore applications in image arithmetic

## Technologies Used

- Python
- Qiskit
- Quantum Computing
- Reversible Logic Gates
